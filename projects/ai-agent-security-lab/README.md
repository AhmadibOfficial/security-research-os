# Project 09 — AI Agent Security Lab

A **synthetic trust-boundary and tool-authorization simulator**. Tests whether a proposed tool action is allowed under an explicit origin, privilege and approval policy. Retrieved content can never manufacture higher priority authority. No real agent, LLM API, terminal tool, email service or financial transfer is invoked.

Run `python3 policy_lab.py fixtures/trust-boundaries.json` during the consolidated verification phase.

This is not a complete prompt-injection evaluation suite. Future iterations need isolated, instrumented mock agents, adversarial corpora, indirect injection tests, realistic permission delegation, and evidence-backed failure classification.
