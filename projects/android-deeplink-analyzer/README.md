# Project 07 — Android Deep-Link Analyzer

Source-only, static Android manifest-XML inventory for web deep links and exported activity aliases. It records browsable VIEW filters and candidate configuration concerns. It does **not** launch intents or assert that any activity is exploitable.

Use `python3 analyzer.py fixtures/synthetic-manifest.xml`. Add Android platform semantics, Digital Asset Links verification, URI matching and dynamic authorization evidence in later stages.
